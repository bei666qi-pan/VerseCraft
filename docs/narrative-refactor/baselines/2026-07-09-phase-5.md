## 4. DB 依赖说明

以下功能需 `db:push` 后才真正生效（当前 fail-open 降级为空）：

1. **foreshadow_ops 写入**：`insertForeshadowLedgerRows` → `narrative_foreshadow_ledger` 表
2. **due foreshadow 读取**：`readDueForeshadowEntries` → directive 中出现伏笔回收提示
3. **过期扫描**：`expireOverdueForeshadows` → 标记超期伏笔
4. **settlement 高光**：`highlights` 字段需从 `narrative_pacing_ledger` 查询 is_payoff/hookType 填充

当前状态：所有新功能在表不存在时优雅降级，不影响在线回合。
