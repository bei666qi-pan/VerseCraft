### 3.3 OPENING_SYSTEM_PROMPT

- beat 方向改为四方向差异化：探索环境/接触在场的人/清点自身状况/观察风险与出口
- 允许一条带小聪明或歪点子的选项
- 保留 `isOpeningSystemUserMessage` trim 对齐

### 3.4 章节 beats + 任务链文案

**Chapter 1 beats 重写** (`definitions.ts`)：
- `arrival` → `wake`（落地求生）
- `survival` → `first-contact`（第一个人）
- `first_contact` → `first-anomaly`（第一处诡异）
- `opening_choice` → `first-choice`（第一次选择）
- `hook` → `hook`（章末钩子）
- endHook → `"门后更深的回声已经指向下一层。"`

**`progress.ts` 新增 beat 映射**：
- `first-contact` → `hasNarrative(progress)`
- `first-anomaly` → `progress.turnCount >= 2 || hasStateChange(progress)`

**5 个开局任务文案重写** (`taskV2.ts createStageOneStarterTasks`)：
- `main_escape_spine`：desc 细化十日时间线，playerHook 加"没时间闲聊"
- `b1_survival_rhythm`：desc 三要素齐备（补给/灯灭/情报），nextHint 具体到储物间+配电间
- `escape_route_fragments`：desc 加"空话不值钱"，playerHook 加"能验证的东西"
- `main_escape_b2_access`：desc 加"白闯的后果你不会想知道"，nextHint 加"她会开价"
- `main_escape_cost_trial`：desc 加"割不割、割什么、割了之后怎么活"，playerHook 加"不会长回来"
