# VerseCraft 叙事风格宪法 v3.0

> 本文件是所有文风改动的**唯一依据**。代码中的机器投影是 `src/lib/narrativeStyle/styleBible.ts`（结构化 profile）与 `src/lib/narrativeStyle/styleValidator.ts`（判据实现），两者必须与本文件同步修订（协议见 §13）。
> 执行者注意：本文件写"应该是什么"；各 phase 文件写"怎么改过去"。改代码时以 phase 文件为操作指引，以本文件为质量标准。

---

## §1 定位与读者

**一句话文风定义 v3**：
以第一人称"我"展开的中文青春悬疑冒险互动小说——目标与代价永远清楚，钩子一回合一个不断档，人物有声音有温度，诡异是世界的事实而不是阅读的刑罚；长短句交错、对白驱动、自嘲有度，读起来像追一本舍不得关掉的连载。

**读者画像**：习惯手机竖屏碎片阅读的网文读者（不限性别），愿意看悬疑冒险，但会被持续压抑劝退。判断标准：一个从不看恐怖小说的人，也能连读十回合并想知道后面发生什么。

**与 v2 的关系**：v2（`youth_campus_suspense_v2`，"电影感强、长句蓄势短句断喝、克制自嘲与命运感并存"）方向没错，但只停留在 prompt 里的一句话，实际输出并未兑现（见 §10 诊断：零对白、零幽默、意象循环、选项预告尾巴）。v3 的改法是：把风格拆成**可执行、可验证的具体条款**，并配运行时节奏指令与校验闭环，不再指望一句话文风描述自动生效。

## §2 五个情绪档位与配比

每个回合提交后归入一个**主档位**（允许副档位）。档位是节奏系统的最小单位（phase-2 落地为 `registerClassifier` + 节奏账本）。

| 档位 | 代号 | 功能 | 滚动 10 回合占比参考 |
|---|---|---|---|
| 悬疑推进 | `suspense` | 主线牵引、信息差、暗流（默认档） | 35–45% |
| 智斗/探索 | `wit` | 目标感、解法可复盘的"聪明时刻" | 15–25% |
| 幽默/日常 | `levity` | 亲近感、张弛、人物烟火气 | 10–20% |
| 温情/羁绊 | `warmth` | 人物温度、关系推进、留存钩 | 10–15% |
| 高燃/爽点 | `payoff` | 情绪回报：翻盘、兑现、认可、小胜利 | 5–10% |

**恐怖压迫不是独立档位**，是 `suspense` 档内的调味：单回合内恐怖浓度不得从头贯到尾；峰值之后必须在同回合尾部或下一回合给情绪出口（自嘲、对白、小胜利、温情任一）。

**节奏法则**（phase-2 由节奏指令 packet 与软守卫执行）：

1. **三回合法则**：任意连续 3 回合不得同一主档位贯穿。
2. 高压回合（beat 为 peak/pressure）之后的回合必须包含缓和元素。
3. 缓和（levity/warmth 为主档）不得连续超过 2 回合。
4. 每章（参考 `src/lib/chapters/definitions.ts` 的章节粒度）至少：1 次大爽点、2 次小爽点、1 次温情拍。
5. **倒计时表面化**：十日窗口与暗月（第 3 日起）是世界既有机制，每 3–5 回合用世界内方式自然提醒一次时间压力（一句即可），不做焦虑轰炸。

## §3 回合微结构（四拍）

普通回合的正文骨架，按顺序：

1. **承接拍**（开头 1–3 句）：直接给出玩家上一步行动的**结果**，主语是"我"，吸收而不是转述玩家输入。禁止用环境铺陈开头晾着玩家的动作。
2. **推进拍**：场景、信息或 NPC 反应向前走，必须带来至少一个"**新东西**"（新信息 / 新画面 / 新人物瞬间 / 新代价），不许原地打转。
3. **变化拍**：本回合的转折、发现、代价或关系变化——即结构化字段（任务、线索、好感、物品、理智）的叙事对应物。结构化状态是事实，叙事是呈现，两者必须互相印证。
4. **收束拍**（最后 1–2 句）：类型化钩子（§4），戛然而止。**禁止选项预告尾巴**（"我能…也能…或者…"），选项由 UI 单独渲染。

短回合（micro 预算）可以压缩为"承接拍 + 收束拍"。`system_transition` / `ending` 回合按各自既有规则，不强套四拍。

## §4 钩子分类学

收束拍必须落在以下五型之一（phase-0 落地为 hookTaxonomy 检测）：

| 类型 | 代号 | 定义 | 示例形态 |
|---|---|---|---|
| 悬念钩 | `question` | 抛出未解的问题或异常事实 | "毽子比我离开时，多了一只。" |
| 危机钩 | `threat` | 威胁逼近、倒计时、退路收窄 | "刮擦声停了。停得太整齐。" |
| 抉择钩 | `dilemma` | 两难摆上桌，代价可见 | "他要的报酬不是东西，是一个名字。" |
| 情感钩 | `bond` | 关系变化、牵挂、亏欠 | "她没问我要不要，只是把伞塞了过来。" |
| 揭示钩 | `reveal` | 半截真相，回收已埋线索 | "登记表的另一半上，是我的名字。" |

**轮换规则**：同型钩子不得连续使用超过 2 回合；每章五型至少出现 4 型。钩子必须留在**世界内**——是剧情自己悬着，不是叙述者对读者喊话。

## §5 爽点系统

爽点 = 玩家投入（时间、选择、冒险）得到的情绪回报。本世界适用的爽点类型：

- **智斗胜利**：用已展示的信息解开局面（解法必须可复盘，呼应 `_narrative_audit.used_fact_ids` 的强事实审计——不许凭空掉答案）。
- **险境翻盘**：代价换生机，赢得狼狈但真实。
- **获得认可**：NPC 态度因玩家行为发生可感知的转变（对应 relationship_updates）。
- **收获可视化**：关键道具/许可/线索到手的瞬间写出分量（对应 awarded_items / clue_updates）。
- **伏笔兑现**：早前细节回收（phase-5 的伏笔账本负责调度）。

**频率**：小爽点每 4–6 回合一次；大爽点每章至少一次，且优先安排在章节 endHook 或任务里程碑上。爽点回合的写法：短句率提高、一次只兑现一件事、兑现瞬间不解释不抒情（见 §10 对照六）。

## §6 语言规范

**人称**：第一人称"我"，硬契约不可改。内心吐槽（自嘲、碎碎念）允许且鼓励——这是拉近读者的主要手段——但每回合不超过 2 处，重大时刻（死亡、告别、大揭示）不用吐槽消解。

**句子**：长短交替是底线（遥测 `sentenceLengthSpread` > 2）；高压场景提高短句率，日常场景允许舒展。全回合句长持平（流水账腔）是失败。

**段落**：移动端优先。单段以 ≤100 字为准（渲染层 `autoParagraphizeNarrative` 的自动切分阈值即 100 字，主动分段永远优于被动切分）；对白单独成段。

**对白**：在场存在可对话 NPC 的回合，对白占正文 20–40%。每句对白必须有当下目的（要东西、探底、警告、掩饰）；说话要口语、具体、带人物句式（§8 voice card）；对白后必须落地——动作、表情或环境呼应（已有 `dialogue_ungrounded` 检测），禁止悬空的连续对白和解释腔长对白（已有 `dialogue_over_explains`）。

**感官**：每 100 字感官词 ≥2.5（已有 `sensory_density_low` 阈值），但感官要靠**具体名词 + 动词**（"铁门凉得咬手"），不许靠形容词堆叠。

**比喻**：每段至多 1 个明喻；禁止"像…像…又像…"连喻（phase-0 新增 simile_chain 检测）；比喻只服务画面或情绪转折，不为文采而喻。

**意象轮换**：同一核心意象（灯管、走廊、刮擦声、潮湿纸页……）不得连续 2 回合复用；`styleBible.ts` 的 imagery_bank 按楼层与时段分池，轮换取用。

**禁语与禁腔**（在 `styleBible.ts` 现有 forbidden_phrases 基础上扩展，全部进 phase-1 的 profile v3）：

- 选项预告句式："我能…也能…或者…"、"是A，还是B？"式结尾自问。
- 陈词滥调："令人窒息的恐惧"、"无尽的黑暗"、"血腥味弥漫"、"死一般的寂静"。
- 模糊词依赖："仿佛"、"似乎"、"好像"合计每回合 ≤2 次。
- AI 腔："值得注意的是"、"与此同时"作段首连接词滥用、"渐渐地"滥用。
- 既有禁腔继续：客服腔、守则腔、说明书腔、系统播报腔（`mechanical_exposition`）、爽文腔与规则怪谈守则腔（`style_drift`）。

## §7 诡异与恐怖使用规范

1. **诡异靠事实差异，不靠形容词轰炸**："毽子多了一只"比三行阴森修辞更瘆人也更好读。
2. 血腥暴力点到为止，不写虐待细节、不渲染尸体特写；危险的分量用代价与后果表达。
3. 恐怖峰值后必须给情绪出口（同回合尾部或下一回合）：自嘲、对白、小胜利、温情任选。
4. 夜晚与暗月阶段允许张力升档，但升的是**悬疑浓度与代价**，不是绝望感；玩家始终要能看见"值得往前走的理由"（线索、许诺、人）。
5. 死亡要死得清楚、死得有戏剧性；结算文本负责"意难平 + 再来一局"的动机（phase-5）。

## §8 人物魅力规范（voice card）

每个主要 NPC 一张声音卡（phase-4 落地到 `majorNpcDeepCanon.ts` 与 `NPC_SOCIAL_GRAPH.speech_patterns`）：

| 字段 | 说明 |
|---|---|
| 一句话性格 | 已有设定，保持 |
| 说话习惯 | 句式长短、口头禅、语气词、沉默习惯 |
| 幽默/反差位 | 该人物的"意外一面"，反差是记忆点 |
| 情感底线 | 什么事绝不开玩笑（对应 taboo，认知边界照旧） |
| 典型一句 | 一句原创示例台词，few-shot 用 |

**六辅锚的现有人设锚点**（重写声音卡时必须回收，不许推翻）：欣蓝"总留半行让你自己填"、北夏"夸东西时像在估你的人"、灵伤"笑容太亮、句尾空半拍"、枫"笑完眼尾一点冷"、叶"像在辨认你的轮廓"、麟泽寡言但可靠。

**幽默功能位**：指定 2–3 个 NPC 承担 levity 档的主要输出（候选：北夏、枫，以及 B1 任务链里的电工老刘——执行时以 registry 实际 NPC 数据为准）。幽默不消解危险，最好反而**夹带信息**（见 §10 对照四）。

**群像原则**：龙族式群像的可迁移技法是——日常打闹建立亲近，关键时刻兑现可靠；每个出场 NPC 至少有一个"当下目的"，没有目的的 NPC 不开口。

## §9 参考技法拆解（版权红线内）

> **红线**：只提炼**叙事技法**。禁止出现参考作品的作品名、作者名、人物名、专有名词、可识别桥段与任何原文；prompt 中"不引用现实作品篇名、作者或名台词"的既有规则继续保留。以下技法描述本身也不得写入任何 prompt——写入 prompt 的只能是本宪法各条款的中性表述。

**来自"青春幻想群像"一系的技法**（对应用户参考之一）：

1. 自嘲式第一人称吐槽：主角损自己不损世界，紧张前后各给一口气。→ §6 人称条款。
2. 日常与史诗的反差蓄能：温吞日常铺得越实，爆发越重。缓和拍不是浪费，是蓄能。→ §2 法则 2/3。
3. 群像反差萌：冷面者的笨拙温柔、嬉皮者的关键可靠。→ §8 幽默/反差位。
4. 细节回收式情感重锤：早期不起眼的小细节在关键节点回收，形成情感暴击。→ §5 伏笔兑现 + phase-5 账本。
5. 命运感落在具体物件与动作上，不落在抽象抒情上。→ §6 感官条款。

**来自"生死局无限流"一系的技法**（对应用户参考之二）：

1. 目标与代价前置：每个局面开场先让读者清楚"要赢需要什么、输了失去什么"，然后再给变数。→ §3 推进拍 + 任务文案规范（phase-5）。
2. 章末钩子链 + 类型轮换：每回合收束拍必有钩，型不重复。→ §4。
3. 智斗可复盘：解法只用已展示的信息，读者拍大腿而不是翻白眼。→ §5 智斗胜利 + used_fact_ids 审计。
4. 倒计时压迫感：明确的时间与资源压力制造推进感。→ §2 法则 5。
5. 生死局里的插科打诨：队友人味是恐惧的解毒剂。→ §8 幽默功能位。
6. 单元关卡 + 主线缓释双层结构：每层楼/每个异常是单元，根真相按揭示门闸缓释。→ 与现有 revealGate / 章节体系天然吻合，phase-5 强化。

## §10 现状样本诊断与正反例对照

### 现状样本（摘自仓库，用于对照；来源标注真实）

**样本 B**（`src/lib/ai/mock/mockScenarios.ts` normalNarrative，现风格代表）：

> 我贴着墙根停下脚步，走廊尽头的灯管像被冷水泡过一样闪了两下。门缝里传来的不是脚步，而是一阵被压低的刮擦声，仿佛有人正用指节慢慢划过旧漆。……这一次，动静没有立刻逼近，更像是在试探我的位置。我能继续沿墙靠近，也能先确认身后的退路，或者利用随身物件制造一点声响，把走廊深处的东西引出来。

逐条问题：不承接玩家具体行动；一段三个比喻（像冷水泡过 / 仿佛指节划漆 / 更像试探）；全段零对白零人物；情绪单档位（压迫）；结尾是标准选项预告尾巴。

### 对照一：承接拍

**现状**（环境铺陈开头）：
> 我贴着墙根停下脚步，走廊尽头的灯管像被冷水泡过一样闪了两下。

**改后**（设玩家输入是"我把碎纸团丢向暗处"）：
> 纸团砸进暗处，弹了两下，没滚出来。
> 像被什么东西——接住了。

要点：首句直接给玩家行动的结果；意外用事实呈现；两句就够，然后再展开。

### 对照二：比喻纪律

**现状**（开场文案的三连喻）：
> ……像钟声、像雷鸣、又像教堂最深处那口生锈了上百年的铜钟忽然被重重敲响。

**改后**：
> 那两个字不响，却压得整间教室的空气矮了一截。

要点：一喻封顶，动词扛画面；三连喻删两个，剩下的那个必须最准。

### 对照三：收束拍（禁选项预告）

**现状**：
> 我能继续沿墙靠近，也能先确认身后的退路，或者利用随身物件制造一点声响，把走廊深处的东西引出来。

**改后**（危机钩）：
> 刮擦声停了。
> 停得太整齐——像对面也在数我的呼吸。

要点：钩子留在世界内；选项交给 UI；短句收束。

### 对照四：对白与幽默夹带信息（levity 档）

**改后示例**（北夏，人设锚点"夸东西像在估人"）：

> "哟，还活着呢。"北夏从保安室探出半个身子，上下打量我，像在给一件二手货估价，"气色不错，能换两包压缩饼干。"
>
> 我把登记单拍在窗台上，没接他的话。
>
> 他笑容没变，指尖却在单子边缘轻轻敲了两下——三短，一长。这栋楼里，这是"别多问，快走"的意思。

要点：对白有目的、有人物句式；幽默不消解危险，反而夹带信息；对白后落地到动作。

### 对照五：诡异靠事实差异（suspense 档 + 情绪出口）

**改后示例**（阿花的毽子，人设锚点"3F 楼梯间踢黑毽子"）：

> 三楼楼梯间，阿花不在。她的毽子还在原地——比我上次路过时，多了一只。
>
> 两只黑毽子并排摆着，鸡毛梳得整整齐齐，像一双在等人的鞋。
>
> 我盯了三秒，决定当作没看见。在这栋楼里，装傻是最便宜的护身符。

要点：诡异核心是"多了一只"这个事实差异；收尾自嘲给情绪出口；零恐怖形容词。

### 对照六：爽点回合（伏笔兑现 + 短句高潮）

**改后示例**（欣蓝，人设锚点"总留半行让你自己填"）：

> 口袋里那半张登记表突然发烫。
>
> 我抽出来，把缺口对上欣蓝那天留给我的半行字——严丝合缝。
>
> "通行许可：持表人，一名。"
>
> 三天前她说"剩下的你自己填"，我以为是客气。
>
> 原来她早就把我的名字，写在了我看不见的那一半上。

要点：回收已埋细节；兑现瞬间不解释不抒情；短句递进；情感钩与揭示钩双收。

### 对照七：温情拍（warmth 档）

**改后示例**（灵伤，人设锚点"笑容太亮、句尾空半拍"）：

> 灵伤把最后一格能量块塞进我手里，笑得照旧太亮，句尾照旧空了半拍。
>
> "拿着。你比我需要——"
>
> 那半拍里，她飞快看了一眼自己空掉的补给箱，又把箱盖合上，像什么都没数过。

要点：温情靠动作细节，不靠抒情词；人设锚点（句尾空拍）成为叙事资产。

## §11 选项写作规范

四条选项本身也是文本产品（渲染于 `MobileOptionsDropdown`，经 `filterNarrativeActionOptions` 过滤）：

1. **方向差异化**：四条必须是四个不同的行动方向（进攻/回避/交涉/巧思），不是同一动作的四种措辞。
2. **代价可嗅**：至少 2 条能让玩家预感到不同的代价或收益倾向。
3. **一条"歪点子"**：场景允许时，保留一条剑走偏锋、带点玩家人格的选项（"我把毽子摆成三只，看它怎么办"）——这是选项层的幽默位。写之前确认能通过 `filterNarrativeActionOptions` 与 `isOverGenericNarrativeOption` 的过滤规则（以代码为准）。
4. 第一人称、≤40 字、可执行的具体动作；禁止"查看背包"类 UI 操作与"继续探索"类空泛项（已有过滤器兜底，但源头就不要产）。

## §13 版本与修订协议

- 本文件当前版本 **v3.0**。任何修订：bump 版本号 → 同步修订 `styleBible.ts` profile 与 `styleValidator.ts` 判据 → 重跑全套 eval 并与 baselines 对比 → 更新 `docs/narrative-refactor/baselines/`。
- 若修订改变了 stable prompt 的语义边界，必须同步 bump `VERSECRAFT_DM_STABLE_PROMPT_VERSION`（消费与缓存机制见 `playerChatSystemPrompt.ts` 文件头注释）。
- `styleBible.ts` 的 `style_profile_id` 在 phase-1 升级为 v3 标识；执行时必须先 grep 该 id 的全部消费方（遥测、缓存、评测）确认无硬依赖后再改，旧值→新值记入 PROGRESS.md。
