# xingni-qingshi-quest-runtime Specification

## Purpose

规定青石县生产版主线、三艺、NPC 支线、重复委托、确定性事件与登记行动的权威任务状态机。

## Requirements

### Requirement: 青石县提供五章权威主线
系统 SHALL 登记五章、十四个权威任务阶段，并只通过结构化行动和前置条件推进；预计首轮由四十五至七十个有效回合完成。

#### Scenario: 玩家推进主线
- **WHEN** 玩家在正确地点向登记 NPC 提交满足条件的行动
- **THEN** 裁决器推进且最多推进一个登记阶段并返回当前目标

#### Scenario: 正文声称跳章
- **WHEN** 模型正文声称玩家已完成未满足前置的章节
- **THEN** 权威任务阶段保持不变

### Requirement: 三艺路线均可选择且不互斥
系统 MUST 提供战斗、炼丹、炼器三条三至四阶段凭证链，并允许任意两条满足升仙试资格；未选择的第三条仍可完成。

#### Scenario: 非专长灵根完成路线
- **WHEN** 任意灵根满足一条凭证链的登记条件
- **THEN** 系统允许完成并授予一次对应凭证

### Requirement: 固定支线与重复内容可审计
系统 MUST 登记八条 NPC 个人支线、四类有每日奖励上限的重复委托和十二个基于存档、日期、地点确定性选择的微事件。

#### Scenario: 重放同一事件选择
- **WHEN** 相同存档在相同日期和地点查询微事件
- **THEN** 系统返回相同事件 ID 且不临时创建事件

### Requirement: 登记行动具备幂等与失败关闭
系统 MUST 只结算登记 action type、目标和稳定 ID，重复幂等键不得再次扣费、发奖或推进任务。

#### Scenario: 重放已结算行动
- **WHEN** 客户端重复提交已记录的幂等键
- **THEN** 系统返回重复结果并保持状态与资源不变

#### Scenario: 提交未知权威实体
- **WHEN** action 引用未登记 NPC、地点、敌人、物品、配方或任务
- **THEN** 系统拒绝结算且不从 narrative 补建实体
