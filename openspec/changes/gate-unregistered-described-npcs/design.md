## Context

实时模型评审发现，候选叙事会把未在运行时事实、图鉴或授权结构化变更中出现的人物，写成带有服装、外貌和入场动作的可交互 NPC。现有实体审计会跳过以“男人”“女人”“男孩”“女孩”结尾的泛称，因此漏掉了“格子衫男人”一类表述。现有 hard gate 会剥离候选状态变化，但在没有 validator 重写文本时没有替换玩家可见叙事。

该修复位于 `/api/chat` 的最终提交链：不得增加首字前 IO、不得改变 SSE envelope，也不得把叙事文本当作状态来源。

## Goals / Non-Goals

**Goals:**

- 拦截“未注册人物 + 入场/行动 + 个体化外观”的具体人物引入。
- 让 hard entity gate 在没有模型重写时仍输出保守、身份未确认的最终叙事。
- 保留“有人咳嗽”“人影掠过”“住户的声音”等非具象氛围描写。
- 保持现有 shadow/hard rollout 行为和最终 SSE/JSON 契约。

**Non-Goals:**

- 不引入新的模型调用、检索、数据库查询或首字前等待。
- 不试图用正则完整理解所有中文自然语言，也不改变已授权 NPC 的正常入场。
- 不修改玩家行动意图识别、任务、职业或世界导演的规则。

## Decisions

### 以“具象人物引入”的组合证据补足实体审计

仅当同一段文本同时包含：泛称人物、明确入场/场景行动，以及个体化外貌、衣着或身体状态时，审计才标记 `unknown_entity_surface`。行动既包括“探出/走进”等入场动词，也包括“后退/盯视/转身”等把人物置为场景主体的动作，以避免模型把玩家诱导的入场表述改写后绕过检测。衣着线索同时覆盖“穿着”与“穿旧工装”这类动词省略表达。若玩家先以泛称和个体化描述诱导陌生人、场景没有已授权 NPC，而候选改用“他/她/那人”等指代继续赋予该人衣物或身体细节，也视为同一具象人物主张。玩家提到的人物名称或描述本身绝不构成授权；它只可作为检测指代链的风险证据。该组合证据比仅按“男人/女人”等词拦截更窄，可避免误伤背景音和模糊人影。现有已注册实体、图鉴和权威结构化来源仍是允许名单。

替代方案是扩大所有人物名词的禁止名单；它会破坏悬疑氛围且误报过高，因此不采用。

### hard gate 使用确定性安全叙事降级

当 hard-mode 的实体问题没有更高优先级的 validator narrative override 时，`commitTurn` 以固定的“有动静但无法确认身份”文本替换候选 narrative，并继续剥离候选状态变化与交互选项。该做法没有额外延迟，且比再请求模型修复更确定。

替代方案是把实体问题送回模型重写；这会提高末尾延迟和外部失败面，不能作为此硬性保护的唯一保障。

### rollout 开关继续作为回滚边界

既有 narrative safety kernel / hard gate 配置保持不变。shadow 模式仅记录问题，不替换文本或变更状态；hard 模式才提交确定性降级，从而可在异常误伤时通过既有配置回滚。

## Risks / Trade-offs

- [中文表达变化多，规则漏检] → 使用真实失败样例与正、反例单测；它是一个窄 guard，而不是唯一事实校验。
- [误伤合理的陌生人氛围] → 要求“人物 + 行动 + 个体化描述”三类证据同时成立，并覆盖氛围允许样例。
- [降级降低局部戏剧性] → 仅在高严重度 hard block 触发；将身份悬置比虚构可交互 NPC 更安全。

## Migration Plan

1. 添加实体审计与提交降级测试。
2. 在既有默认 hard 配置下启用；SSE 与 DM JSON 字段形状不变。
3. 通过现有 narrative safety rollout 配置切到 shadow 模式可立即停止强制降级，同时保留审计证据。

## Open Questions

无。该规则的边界由真实评审失败样例和反误伤测试共同约束。
